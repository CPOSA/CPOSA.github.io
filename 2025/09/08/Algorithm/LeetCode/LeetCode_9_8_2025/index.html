309 买股票的最佳时机含冷冻期

DP 5 部曲分析

  1. 确定dp数组及其下标含义
    dp[i][j], 第i天的状态为j,当天所剩余的现金为dp[i][j]
    分为四种状态：
    • 状态1：持有股票(今天买入，或之前买入一只持有)
    • 不持有股票
      • 状态2：刚卖出股票
      • 状态3：之前卖出股票，度过一天冷冻期，或一直没有买入股票
    • 冷冻期
  2. 确定递推公式
    • 到达状态1：dp[i][0]
      • 前一天就是持有状体：dp[i][0] = dp[i-1][0]
      • 今天买入：dp[i][0] = dp[i-1][2] - prices[i]
      • 前一天是冷冻期：dp[i][0] = dp[i-1][3] - prices[i]
      • 那么dp[i][0]就是取最大
    • 到达状态2：dp[i][1]
      • 之前持有股票：dp[i][1] = dp[i-1][0] + prices[i]
    • 到达状态3：dp[i][2]
      • 刚过完冷冻期：dp[i][2] = dp[i-1][3]
      • 之前一直没有买入：dp[i][2] = dp[i-1][2]
      • 那么dp[i][2]就是两者取最大
    • 到达状态4： dp[i][3]
      • 前一天卖出股票：dp[i][3] = dp[i-1][1]
  3. 递推公式如何初始化
    dp[i][0]只能初始为0
  4. 确定遍历顺序
    dp[i]依赖于dp[i+1],所以是从前往后遍历
  5. 举例推导dp数组，找到返回值
    取状态2，3，4最大值
